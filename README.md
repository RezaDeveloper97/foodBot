# ربات دستور پخت تلگرام

رباتی که زمان‌بندی‌شده از Spoonacular دستور پخت می‌گیرد، با AI آن را به فارسی بومی‌سازی می‌کند و در کانال تلگرام منتشر می‌کند.

## معماری

دو مرحله‌ی جداگانه:

- **Fetcher** — طبق زمان‌بندی (پیش‌فرض: هفته‌ای یک بار) یک batch دستور پخت می‌گیرد، هرکدام را با مدل AI پردازش می‌کند، عکس را دانلود می‌کند و نتیجه‌ی آماده را در صف ذخیره می‌کند.
- **Publisher** — طبق زمان‌بندی (پیش‌فرض: روزی دو بار) قدیمی‌ترین آیتم آماده را از صف برمی‌دارد و در کانال منتشر می‌کند.

جدا بودن این دو یعنی انتشار هیچ‌وقت منتظر یک API کند نمی‌ماند، و اگر لحظه‌ی انتشار سرویسی down باشد محتوای از قبل آماده‌شده سر جایش است.

ذخیره‌سازی یک فایل JSON ساده است (`data/store.json`) — برای این حجم کار کاملاً کافی است. مجموعه‌ی متدهای پکیج `storage` کوچک است، پس اگر بعداً لازم شد می‌توان به‌راحتی SQLite یا Postgres را جایش گذاشت.

de-duplication بر اساس `id` دستور پخت Spoonacular انجام می‌شود؛ یک غذای تکراری دو بار منتشر نمی‌شود.

## ساختار

```
recipe-bot/
├── main.go                       # wiring، زمان‌بندی، خاموش‌شدن تمیز
├── prompt.txt                    # system prompt بومی‌سازی (قابل ویرایش بدون recompile)
├── .env.example
└── internal/
    ├── config/                   # خواندن env + پارسر سبک .env
    ├── storage/                  # صف مبتنی بر فایل JSON
    ├── spoonacular/              # کلاینت API دستور پخت
    ├── ai/                       # کلاینت Anthropic Messages API
    ├── telegram/                 # کلاینت Bot API
    └── pipeline/                 # مراحل fetcher و publisher
```

## راه‌اندازی

```bash
cp .env.example .env
# مقادیر .env را پر کن
go build -o recipe-bot .
./recipe-bot
```

در اولین اجرا چون صف خالی است، fetcher یک بار همان ابتدا اجرا می‌شود تا برای اولین انتشار محتوا آماده باشد.

## نکات

- **سهمیه‌ی Spoonacular** — پلن رایگان سهمیه‌ی روزانه‌ی محدودی دارد. `FETCH_BATCH_SIZE` را معقول نگه دار.
- **مدل AI** — رشته‌ی دقیق مدل را در `AI_MODEL` بگذار؛ مقدار درست را از مستندات Anthropic بگیر.
- **محدودیت تلگرام** — caption عکس حداکثر ۱۰۲۴ کاراکتر است. اگر متن بلندتر بود، کلاینت اول عکس و بعد متن کامل را جدا می‌فرستد.
- **عکس بدون دانلود** — اگر دانلود عکس fail شود، همان پست به‌صورت فقط-متن منتشر می‌شود (کل batch متوقف نمی‌شود).
- ربات باید **ادمین کانال** باشد تا بتواند پست بگذارد.

## زمان‌بندی

عبارت‌های cron استاندارد ۵-فیلدی هستند:

- `FETCH_CRON=0 3 * * 1` — ساعت ۳ بامداد هر دوشنبه
- `PUBLISH_CRON=0 12,20 * * *` — ساعت ۱۲ ظهر و ۸ شب هر روز
